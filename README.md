# 🍝 Symmetrical Couscous

[![Python 3.x](https://img.shields.io/badge/Python-3.x-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

> *Магическая сортировка массива по принципу "симметрии кускуса" — алгоритмический эксперимент на грани абсурда и красоты*

## 📖 Описание

**Симметрично-кускус** — это уникальный алгоритм, который преобразует массив в "симметрично-кускусную" форму. Название проекта вдохновлено текстурой кускуса: крупинки данных переставляются так, чтобы создать идеальный (но, возможно, бесполезный) зеркальный узор.

## 🎯 Как это работает

Алгоритм:
1. Принимает массив чисел
2. Зеркально отражает элементы с плавающим шагом
3. Возвращает "симметрично-кускусный" массив
